# Dancing Script font provenance

The site serves `dancing-script-latin-700.woff2` locally. It is the unmodified
Latin, normal-style, weight-700 file supplied by Google Fonts on November 7, 2026.
All current uses of Dancing Script in the site request weight 700. The Latin
subset supports the site's current English project headings and punctuation.

- Official stylesheet: https://fonts.googleapis.com/css2?family=Dancing+Script:wght@700&display=swap
- Official font: https://fonts.gstatic.com/s/dancingscript/v29/If2cXTr6YS-zF4S-kcSWSVi_sxjsohD9F50Ruu7B1i03Sup8.woff2
- Download size: 25,444 bytes.
- SHA-256: `06b326d772e3a68977c10711110f5f38255a007f3775795efbcd3862313b2d22`.
- License: the accompanying `OFL.txt` (SIL Open Font License 1.1).

The stylesheet was requested with a modern Chromium user agent. There is no
Google Fonts request at build time or while visiting the site.

The previous variable file, `dancing-script-latin.woff2` (42,708 bytes), is retained
as a source asset. It is not the font referenced by the application. If additional
weights or writing systems are introduced, choose an appropriate official font
file rather than assuming that this subset covers them.
